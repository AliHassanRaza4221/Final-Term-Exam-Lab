Tetris Game Developed with C++

Tetris

Tetris, a classic puzzle video game developed by Alexey Pajitnov in 1984, challenges players to manipulate falling blocks in such a way that complete lines are cleared from the screen. Its simplicity and addictive nature have made it one of the most iconic video games in history. This project aims to create a version of Tetris using C++ with an added graphical user interface to improve user experience.
